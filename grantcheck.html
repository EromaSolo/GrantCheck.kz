    How GrantCheck.kz works

    Information flow from your phone or laptop to the server and back.

    Applicant (smartphone or laptop)
    Input: UNT score, profile subjects, preferred major. Output: chance in %, alternatives. Interface built with React.
    ↕ HTTPS + REST API
    Web server (Node.js or Python, in the cloud)
    Processing: compares your score with past cutoffs and quotas, calculates the chance, sorts programs.
    ↕ SQL queries
    PostgreSQL database
    Storage: user profiles, cutoff scores by year and major, Ministry quotas.
    Data admin
    Updates cutoffs and quotas after each UNT round
    Email service
    Sends alerts to applicants when data changes
