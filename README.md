# GrantCheck.kz

- Calculator only: open `index.html` (double-click). Everything works without a server.
- With email subscriptions: `node server/server.js`, then open http://localhost:3000. Emails are saved to `data/subscribers.txt` (one `date<TAB>email` per line).
- Edit thresholds in `assets/js/data.js`, the formula in `assets/js/model.js`.
